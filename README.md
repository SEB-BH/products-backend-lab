## Overview

You have been contacted by a local company that needs a **Business Inventory Management System**.

The company wants an application that allows employees to manage their inventory by creating, viewing, updating, and deleting products.

In this lab, you will build the backend API for the inventory system using:

* Express
* MongoDB
* Mongoose
* RESTful API principles

You will create the Product model, build CRUD API endpoints, test your routes using Postman, and optionally add automated testing and GitHub Actions.
